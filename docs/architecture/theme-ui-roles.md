# Declared UI roles

Covers: bin/vshell_helper.py, themes/*/ui-roles.toml

A curated theme package names its own tone for a derived UI role in `ui-roles.toml`, and that tone replaces what the palette would derive. Palette, overlay, target and apply contracts are in [theme.md](theme.md).

## Invariants

- A curated theme package's optional `ui-roles.toml` declares derived UI roles, keyed by the names `target_roles` emits. `DECLARABLE_UI_ROLES` in `bin/vshell_helper.py` owns the set and holds the surfaces and containers, `outline`, `outlineVariant`, `muted`, `dim`, `statusBg`, `secondary`, `tertiary` and the `on*` companions of those; the semantic `error`, `warning`, `success` and `info` family and the `inverse*` roles are outside it and a key naming one is refused by name. Each of those roles is otherwise derived from the palette with no way for a vendor to supply its own: `outline`, `outlineVariant`, `muted` and `dim` are a blend of background and foreground pulled toward black or white by the contrast guards; `surfaceVariant`, the `surfaceContainer*` roles and `statusBg` are a lightness shift of the background alone; `surface`, `surfaceContainerLowest` and the three `on*` accent companions are the background verbatim and the `on*Container` roles the foreground verbatim; `secondary`, `tertiary` and the three containers are tinted from the palette's own cyan, magenta and accent. `parse_colors_toml` reads it as `ColorsRead.ROLES`, because `normalize_color_map` emits only `COLOR_KEYS` and drops every role name. `package_overlay_values` is the one reader, layer by layer, and every key a layer states is honoured or named: a key naming no declarable role on one line, and a key whose value is not a six-digit hex on another, from the `discarded` list the parser fills, since such a value never enters the parsed map. The loose matugen-shaped fallback is skipped for this file. `declared_ui_roles` is the one owner of the curated test, called by the render, the carry and the digest fold, so a generated blueprint carries and digests none. `declared_or` inside `target_roles` is the one input: the derivation runs either way and a declaration replaces its result, so an undeclared role derives exactly as before. Each call takes its role out of a copy of what the package declared, so a declared role no assignment reads is named at runtime; the `everyroles` fixture in `scripts/check-vshell-helper.py` declares the whole set and reads each value back, which is what holds the set and the assignment sites together. Roles computed from a declared one follow it, so a declared `statusBg` gets its status text and muted text measured against itself. The contrast guards become reporters for a declared role: the tone is written as declared and every rule it misses is named in one warning on the apply result, which makes the apply partial, the same guarantee [agent-cli-themes.md](agent-cli-themes.md) states for a curated Claude Code file. `UI_ROLE_CONTRAST_RULES` holds the rules each role carries and `ui_role_shortfalls` is its one judge, over the base role map alone. Of the roles the table names, only the three accent containers carry two, their declared `on*Container` companion and the palette's own foreground, which the `vgs-shell` target still draws on them; the rest carry one. The five surfaces outside the table carry none and are never measured. A rule landing on a colour an earlier rule for the same declared role already measured is skipped, so a container declared without its companion reports its one defect once. Declared roles are part of the palette identity: `palette_identity` folds them in under `uiRole.`, so a restyle slider moves them with the palette, each measured against the palette's own mean lightness, and the `curatedPalette` digest covers them, because a merge-style curated file's bands are picked against the roles it merges over. `write_user_layer` writes this file in sorted key order, and `with_current_terminal_slots` carries the declarations onto every rebuild from the applied theme. Only a curated save touches the file: a generated save never writes, masks or removes it. `inert_declarations_path` names the unread file once on the apply result, which makes the apply partial, since nothing else says the chrome on screen is derived rather than declared. It asks `package_overlay_values` whether the composed package declares anything, so the masking overlay and a file of unreadable values stay silent, and names the path `compose_theme_files` resolves. Every theme's definitions ship in the package and a release archive carries only imagery, the split [theme-catalog.md](theme-catalog.md) owns, so a download of a theme's wallpapers leaves its declarations in place. `test_declared_ui_roles_replace_the_derivation_without_a_contrast_rewrite` and `test_declared_ui_roles_move_with_a_restyle_and_survive_a_save` in `scripts/check-vshell-helper.py` check the render, the refusals, the reporter, the restyle, the carry and the digest.
