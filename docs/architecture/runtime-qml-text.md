# Runtime: QML text and inline images

Covers: shell/Ui/foundation/ImageText.qml, shell/Ui/foundation/ImagePool.qml, shell/Ui/foundation/ImageTextLogic.js, scripts/qml-tests/tst_imagetext.qml

The Qt 6.11.2 facts `ImageText` and `ImagePool` in `qs.Ui` rest on: how a StyledText `<img>` loads, lays out and elides. Each was read in the qtdeclarative 6.11 source and checked with offscreen probes on host cachy on 2026-09-29. [runtime-qml.md](runtime-qml.md) holds the other QML facts; [components.md](components.md) what the components guarantee.

- A StyledText `<img>` loads its image through `QQuickPixmap(engine, url, QRect(), size * effectiveDevicePixelRatio())` with the default options, `Cache` alone and not `Asynchronous` (`QQuickTextPrivate::setLineGeometry` in `src/quick/items/qquicktext.cpp`, `QQuickPixmap::load` in `src/quick/util/qquickpixmapcache.cpp`). A local file not already in the pixmap cache is read and decoded on the GUI thread.
- An asynchronous `Image` adds its entry to the pixmap cache while it still loads, before its reader thread starts the job (`addToCache` before `startJob` in `qquickpixmapcache.cpp`). A later `<img>` request with the same key finds that entry and waits on its load (`connectFinished`, then `imageDownloadFinished`), and draws when it lands. The key is the URL, an empty clip region, the request size, frame 0 and the default provider options, so the `Image` keeps the default fill mode and no clip, and sets `sourceSize` before `source`. `QT_LOGGING_RULES=qt.quick.image.debug=true` shows it: one `adding QQuickPixmapKey(... size=22, 22)` from the pool, then `loaded from cache` for each text, then the reader thread's decode (`scripts/qml-tests/tst_imagetext.qml` under `scripts/qml-unit.sh` on 2026-09-29).
- For a PNG, `Image` requests exactly its `sourceSize`: its device pixel ratio stays 1 unless an `@2x` file exists (`QQuickImageBasePrivate::updateDevicePixelRatio`). A text requests its image's width and height times its window's effective device pixel ratio. `ImagePool` takes `Screen.devicePixelRatio`, the repository's convention, which equals the window's ratio on the owner's integer scales, 2, 1 and 2 (`hyprctl monitors` on 2026-09-29). On a fractional scale the two keys can differ: the text then decodes the small normalized PNG itself, synchronously, and draws the same image.
- Qt's multi-line `ElideRight` misplaces StyledText images. It lays the elided last line out in a separate `QTextLayout` whose text starts at 0, and `setLineGeometry` matches images by their absolute position in the text, so an image of the first line whose position is below the elided line's length is drawn inside the elided line, over its text; an image of the full last line past the elide point also stays in `visibleImgTags` and draws. A probe drew `one [red] two ...` with the red square inside "eigh|t" on line 2. `ImageText` therefore elides a text with images itself, with `elide: Text.ElideNone`.
- StyledText writes an image as a space, `floor(width / nbspWidth)` no-break spaces and a space (`parseImageAttributes` in `src/quick/util/qquickstyledtext.cpp`), so word wrap never breaks inside an image. `WrapAnywhere`, which Qt switches on for the last line under multi-line elision, could; with `Text.ElideNone` it stays off.
- `Text.WordWrap` with `Text.ElideNone` lets a word wider than the line run past the width: a 60-character word read 600 px wide in a 400 px text. `Text.Wrap`, `WrapAtWordBoundaryOrAnywhere`, lays each line out at word boundaries and lays it out again with `WrapAnywhere` only when that line is still wider than the width, which happens when its first word alone is (`QTextLine::layout_helper` in qtbase 6.11 `src/gui/text/qtextlayout.cpp`). That line ends inside the long word, so it holds no image, and an image, narrower than any line and after a space, moves to the next line whole. A probe of 40 images between words in a 200 px text drew every image whole. `ImageText` wraps a text with images that way.
- With `align="middle"` an image of height `ih` sits at `textHeight / 2 - ih / 2`; a positive offset moves the line's text down, and an image taller than the line grows the line box. Liberation Sans at 11 px has a line height of 12.28 px: a 12 px image, the line height rounded down, keeps the line pitch, and a 13 or 14 px one grows each line that holds one. `tst_imagetext.qml` holds the pitch at 20 px.
- `Text.truncated` and `lineCount` update at once when `text` is assigned, on a `visible: false` text too: a probe set, read, set and read in one JavaScript function. `ImageText` measures each cut on a hidden copy of the text that way.
