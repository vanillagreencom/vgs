# Hyprland layer wiring

Covers: bin/vgsh-hypr-judge, bin/vgsh, shell/Core/HyprlandLayer.qml, shell/Core/HyprlandLayer.js, shell/Core/Notices.qml, shell/Hosts/NoticeHost.qml, scripts/test-vgsh-hypr.sh, scripts/test-hyprland-layer.js, scripts/smoke/rows/hyprland-consent.sh, scripts/smoke/rows/hyprland-consent-decline.sh

The Hyprland layer is [hyprland.md](hyprland.md). This file holds the line that loads it and the consent question that may add that line.

## The line

`vgsh hypr state` reads `${XDG_CONFIG_HOME:-~/.config}/hypr/hyprland.lua` and prints whether the loading line is `wired`, `unwired` or `absent`. It changes nothing. `vgsh hypr wire` keeps `pcall(dofile, "<state dir>/hypr/vgs.lua")` in that file, first when it adds it. `vgsh hypr unwire` removes every copy. The three verbs follow the theme include line's rule, [theme-wiring.md § Wiring text](theme-wiring.md#wiring-text): a whole-line match, no other byte changed, a symlink resolved and its target replaced with its mode kept, and the file never created. A state directory holding a quote, a backslash or a line break is refused, since the line holds it in a Lua string.

After the first read and any needed layer write and reload in one shell run, the shell runs `vgsh hypr state`. A `wired` or `absent` answer does nothing. An `unwired` answer raises the core notice on the focused screen unless `$XDG_RUNTIME_DIR/vgs/hypr/consent-declined` holds the current `HYPRLAND_INSTANCE_SIGNATURE`. Connect runs `vgsh hypr wire` and then `hyprctl reload config-only`. Not now, Escape and Close write that marker. It applies only to this Hyprland session, because systemd lingering can keep `XDG_RUNTIME_DIR` alive after logout. A failed probe raises no question and is reported as a Hyprland problem; a failed Connect keeps the question open and names the failure. The shell writes nothing under `~/.config/hypr/vgs/` and uses no `require` module name, so v1's generated files and modules are left alone.

The line is first, so every setting after it wins: a later `hl.config` value, `hl.unbind("<keys>")` with the keys spelt as the layer writes them, `hl.layer_rule({ name = "<id>:<name>", enabled = false })`, which Hyprland v0.56.2 applies to the rule of that name, and `hl.window_rule({ name = "vgs:tui", enabled = false })`, which v0.56.2 applies the same way to a floating TUI's rule: a window of that class then tiles, as the sandbox reads back, and the other two classes still float. `hl.window_rule({ name = "vgs:window", enabled = false })` tiles the shell's application windows the same way. A key is better changed in `shell.json`, which needs no edit of Hyprland's files.

To let VGS own an appearance group, remove the user's own later lines for that group. Remove `general.border_size` to let the border thickness token win. Remove `decoration.rounding`, `decoration.rounding_power`, `group.groupbar.rounding` and `group.groupbar.gradient_rounding` to let the radius token win. Remove later `hl.animation` rows for windows, layers, workspaces and fades, plus `animations.enabled`, to let the motion preset win. The owner's existing `decorations.lua` and v1-generated `vgs/layout.lua` set `border_size` and `rounding` after the line, so those values override VGS until they are removed.

## Invariants

1. `state` never creates or edits `hyprland.lua`, and reads `wired` with the same whole-line rule as `wire`. `wire` never creates `hyprland.lua`, puts the line first, keeps a symlink and its target's mode, and refuses a state directory a Lua string cannot hold; `unwire` leaves the file byte for byte as it was. Enforced by `scripts/test-vgsh-hypr.sh` under a temporary HOME, with judge copies that create, skip the quoting refusal, wire on `unwire`, report every run as a change and report an unwired file as wired as its controls.
2. The shell asks before wiring an unwired `hyprland.lua`; Connect wires and reloads; Not now writes the current Hyprland signature to a runtime marker; a restart in the same Hyprland session suppresses the question; a marker from another Hyprland session is ignored; a failed probe raises no question; a failed wire keeps the question open. Enforced by `scripts/test-hyprland-layer.js`, `scripts/smoke/rows/hyprland-consent.sh` and `scripts/smoke/rows/hyprland-consent-decline.sh`, with controls that skip the probe, skip the marker check, skip the marker write, ignore a connect queued during a write and ignore a wire failure.
3. On the nested instance the consent row wires the harness's `hyprland.lua` and changes no other line. Enforced by `scripts/smoke/rows/hyprland-consent.sh`.
