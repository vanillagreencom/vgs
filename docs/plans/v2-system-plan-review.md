# v2 System plan: review dispositions

Review of [v2-system-plan.md](v2-system-plan.md) by a cross-model challenge (gpt-6-astra, `tmp/second-opinion/challenge-codex-detached.dZWlum`). Every claim was checked against the repo before it was accepted. The evidence for each verdict is in the reason column.

Totals: 15 accepted, 4 partially accepted, 1 declined.

| Id | Severity | Finding | Disposition | Reason |
|---|---|---|---|---|
| B1 | Blocker | Monitor recovery depends on the shell | Accept | D069 stops on a clean exit and gives up after five crashes (D069 lines 21 and 53–54), and a hung shell runs no timer. S06 now writes a record and arms a detached `vgsh-monitor-guard` before it applies the preview, and tests stopping the shell, stopping the runner, and failure at each step. |
| B2 | Blocker | Reapplying saved rules does not restore the prior state | Accept | `runtime-hyprland.md:14`: an eval'd mode survives `reload config-only` when no file rule exists. Revert now restores the captured effective state explicitly. Covers first use, unplugged outputs and partial applies. |
| B3 | Blocker | Device-test isolation leaves hardware paths open | Accept | The harness PATH falls back to the host's (`harness.sh:333`), so `rfkill` would reach `/dev/rfkill`. S08 adds an `rfkill` stand-in, null-only WirePlumber with an fd assertion, an `xdg-open` stand-in, and sudo through `sentinel_stand_over` (`harness.sh:233-300`). |
| M1 | Major | The architecture claims crash isolation it does not have | Partially accept | The crash claim is removed (D010: one process), and the `vgs.settings` host (option C) is compared and kept as Q1. The pane contract stays a prerequisite, because both hosts need it. |
| M2 | Major | "One source, two views" contradicts how settings are stored | Accept | `settingTargetOf` and `managerSettings` read the layout entry for a placed widget and the `plugins` row for everything else. Pane writes now use the multi-target `settingTargets` contract, and S01's row edits a setting and reads it back from all four views. |
| M3 | Major | Declared capabilities cannot perform the promised actions | Partially accept | Every issue now carries a capability matrix, and S04 defines a named `hyprland` capability with fixture readbacks. S09 gets placement through a narrow `panes.setPlaced` rather than the full `manager`. |
| M4 | Major | Keyboard switching does not fit the dispatch transport | Accept | `Compositor.qml:57` runs `hyprctl dispatch <pending>`, and `switchxkblayout` is a top-level command. S04 gives it its own argv transport and tests it against a dispatch-routed control and a keymap readback. |
| M5 | Major | Bluetooth power mixes rfkill and BlueZ state | Accept | `omarchy-bluetooth-power:1-61`: rfkill is the state, the wait is confirmed with a fallback, and every controller is covered. S11 now has one power operation with separate soft-block, hard-block, powered and service states. |
| M6 | Major | A discovery counter misses BlueZ's delayed replies | Accept | Omarchy `bluetooth/Panel.qml:520-560` documents a stop being swallowed before BlueZ confirms the start. S11 now separates desired from confirmed discovery, ties leases to the caller's lifetime, and bounds the stop retry. |
| M7 | Major | Pairing claims a session role without core ownership | Accept | D012 gives session-wide roles to the core (the polkit agent precedent, D062). New core item S22 `bluetoothAgent`: an exclusive lease that waits for BlueZ's acknowledgement and handles display passkeys, inbound requests and the busy-default case. |
| M8 | Major | Network discovery and recovery omit the reference's behaviour | Accept | Omarchy has `setScannerEnabled` (`Panel.qml:297-317`) and `shouldRepromptPassphrase` (`Model.js:360`). S12 adds scan leases, the reprompt, and separate absent, stopped, unmanaged and denied states, with wording that never assumes another network manager. |
| M9 | Major | Enterprise Wi-Fi lacks secret protection | Accept | Omarchy's `enterpriseConnectScript` (`Model.js:335-342`) reads the password from stdin and cleans up on failure. New item S23 does the same with offline tests, and decision record 6 records the NetworkManager secret-store exception to D061. |
| M10 | Major | Tailscale exit node uses the wrong identifier | Accept | Omarchy `exitNodeTarget` (`Service.qml:128-134,327-344`) sends a DNS name, host name or IPv4. S13 keeps the UI id separate from the CLI target and adds the poll guard and watchdog. |
| M11 | Major | Sound omits stream moves, DSP sinks and the peak monitor | Accept | Verified `omarchy-audio-output-set-default`, the `volumeSink` logic (`audio/Panel.qml:111-131`), `PwNodePeakMonitor` (`:580`, present in qmltypes) and the crash note (`:102-107`). S10 adds stream moves, DSP-sink resolution, snapshots, and tests on an already-playing stream and a filter-chain graph. |
| M12 | Major | Loading `i2c-dev` is not an access grant | Accept | `pacman -Ql ddcutil` shows `60-ddcutil-i2c.rules` (uaccess on display-class i2c) and `modules-load.d/ddcutil.conf`. | M13 | Major | The Apple assignment fallback has no storable contract | Accept | The schema types (`schemaError`) cannot hold a map. Assignments move to a judged plugin state file, identity becomes USB parent plus serial, and the FIFO fake is replaced by the ioctl seam, since a FIFO cannot answer `HIDIOCGFEATURE`. |
| M14 | Major | Manual configuration remains on the setup path | Partially accept | Q5 now defaults to S24, a confirmed one-click move of v1 rules. Q3 gains a `foreignBinds` "Use my binding" choice. The NixOS snippet stays behind Show command with an explicit "Needs your NixOS configuration" state, as D036 already does, because VGS cannot write a NixOS configuration. |
| M15 | Major | The VPN import test does not run the import | Accept | The stand-in terminal does not run shipped scripts (`validation-smoke-host.md`). S14 adds `test-vpn-import.sh`, which runs the real script against fake `gum` and `nmcli`. |
| E1 | Evidence limit | The v1 constants are unverified | Decline | Verified in this session against the primary source: `vshell_helper.py:340-358` (vendor, products, ranges, ceiling) and `:9866-9896` (report id and length, ioctl encodings, little-endian layout). The plan now says so. |
