# Keys and pointer

- `input.text` types exact text into the current application.
- `input.key` presses a chord written with SUPER, CTRL, ALT and SHIFT.
- `input.click` clicks a button at absolute layout coordinates.
- `input.scroll` sends vertical or horizontal scrolling at those coordinates.
- The policy grants an application for the conversation in Standard. Tainted input still needs confirmation. Cautious confirms each call.
- Jarvis refuses its own effective keys and input to VGS, lock and authentication surfaces. A protected layer's full rectangle includes its pass-through gaps.
- Terminal keys, clicks and scrolling refuse. Terminal text refuses in Cautious and Standard. Trusted shows the exact text for physical approval.
- A command result reports input delivery. It cannot prove the application's effect. Read the application before a dependent action.
